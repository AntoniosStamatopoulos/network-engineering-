! Reserved growth port. Held in VLAN 999 and shut down rather than parked in a
! department VLAN: assigning it before it is needed would create a live port
! into that department with nothing connected to it (3.5.5).
!
interface FastEthernet0/23
 description RESERVED - department TBD
 switchport access vlan 999
 switchport mode access
 shutdown
!
! Access point uplink. Native VLAN 99 rather than 999: the access point sends
! management traffic untagged and dropped to DOWN when VLAN 99 was tagged
! (3.6 — D8). FlexConnect Local Switching means client traffic is switched
! here rather than tunnelled to the controller (3.6 — D10).
!
interface FastEthernet0/24
 description LAP trunk
 switchport access vlan 99
!                    ^^ Inert while the port is in trunk mode — a leftover
!                    from before the port was converted from access to trunk.
!                    Harmless, and left in place so the capture matches the
!                    device.
 switchport trunk native vlan 99
 switchport trunk allowed vlan 10,20,30,40,60,99
 switchport mode trunk
 switchport nonegotiate
!
! ------------------------------------------------------------- Uplink to core
! Single trunk. The second Gigabit port was the dedicated Guest uplink in the
