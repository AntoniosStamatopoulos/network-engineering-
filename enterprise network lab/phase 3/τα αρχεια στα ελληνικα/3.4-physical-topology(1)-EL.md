# 3.4 Φυσική τοπολογία

Αυτό το υποστάδιο καταγράφει ποιες συσκευές συνδέονται μεταξύ τους και πού
βρίσκονται. Μεταφράζει τη λογική δομή της Φάσης 2 και την επιλογή εξοπλισμού του
3.3 σε πλάνο υλοποίησης.

Εδώ αποτυπώνονται δύο συμφωνημένες αλλαγές υλοποίησης:

1. Το VLAN 60 χρησιμοποιεί **Layer 2 transit μέσω του core**, χωρίς VLAN 60 SVI
   στο core και με ένα gateway, `10.0.60.1/24`, στο firewall.
2. Το Packet Tracer χρησιμοποιεί **ένα Cisco 3504 WLC και δύο LAP-PT**, επειδή
   το autonomous AP model του δεν μπορεί να υλοποιήσει τα απαιτούμενα πέντε
   SSIDs.

Ο ακριβής τρόπος του Core→ASA Guest handoff και οι λεπτομέρειες management των
WLC/LAP δεν έχουν επιλεγεί. Παραμένουν ρητά σημειωμένα ως **TBD**, αντί να
αποφασιστούν σε αυτό το έγγραφο.

---

## 3.4.1 Φυσική έναντι λογικής

Το υποστάδιο 2.1 παρήγαγε logical diagram: segments και τις σχέσεις μεταξύ τους.
Αυτό το υποστάδιο παράγει physical diagram: συσκευές και καλώδια.

| | Logical (2.1) | Physical (3.4) |
|---|---------------|----------------|
| **Δείχνει** | Segments και σχέσεις | Συσκευές και καλώδια |
| **Απαντά** | Τι επιτρέπεται | Τι υπάρχει |
| **Στοιχεία** | VLANs, zones | Εξοπλισμός |

Σε αυτόν τον σχεδιασμό, τα VLANs 10, 20, 30, 40, 60 και 99 φτάνουν σε κάθε
access switch μέσω ενός core trunk. Το VLAN 50 παραμένει τοπικό στο core επειδή
οι τρεις servers συνδέονται απευθείας σε αυτό. Το VLAN 60 στη συνέχεια διασχίζει
το core μόνο στο Layer 2 και παραδίδεται στο firewall· δεν δρομολογείται ποτέ
από το core.

Η wireless υλοποίηση του Packet Tracer προσθέτει μία φυσική σύνδεση WLC στο core.
Αυτή είναι προσθήκη μόνο για την υλοποίηση και δεν αλλάζει τον στόχο των δύο
autonomous APs του πραγματικού design.

## 3.4.2 Διάγραμμα φυσικής τοπολογίας

```text
                                      ┌────────────────┐
                                      │  INTERNET / ISP│
                                      └────────┬───────┘
                                               │
                                      ┌────────┴───────┐
                                      │ 4331           │
                                      │ edge router    │
                                      └────────┬───────┘
                                               │ Gi0/0/1
                    ┌──────────────────────────┴──────────────────────────┐
                    │                         ASA 5506                    │
                    │ Gi1/1 outside     Gi1/2 inside                     │
                    │ Gi1/3 Guest: 10.0.60.1/24                          │
                    │ Management: unchanged / physical termination TBD   │
                    └──────────────────────────┬──────────────────────────┘
                                               │ routed inside link
                                      ┌────────┴────────┐
                                      │ 3650-24PS       │
                                      │ CORE            │
                                      └───┬────┬────┬────┘
                                          │    │    │
              trunk: 10,20,30,40,60,99   │    │    │   WLAN VLAN trunk;
                                          │    │    │   management details TBD
                                  ┌───────┘    │    └───────────────┐
                                  │            │                    │
                           ┌──────┴─────┐ ┌────┴──────┐      ┌──────┴──────┐
                           │ 2960 SW1   │ │ 2960 SW2  │      │ 3504 WLC   │
                           └──────┬─────┘ └────┬──────┘      └─────────────┘
                                  │             │
                         LAP path; TBD  LAP path; TBD
                                  │             │
                           ┌──────┴─────┐ ┌─────┴──────┐
                           │ LAP-PT 1   │ │ LAP-PT 2   │
                           └────────────┘ └────────────┘

                    ┌──────────────────────────────────────────────┐
                    │ Core Gi1/0/4 ── VLAN 60 Layer 2 handoff ───► │
                    │ ASA Gi1/3; handoff mode = TBD                │
                    └──────────────────────────────────────────────┘

                         CORE ── access VLAN 50 ──► DNS / Web / Monitoring
```

**Πώς διαβάζεται η Guest διαδρομή:** τα δύο access switches μεταφέρουν το VLAN
60 στα κανονικά core trunks τους. Το core προωθεί αυτά τα frames στο Layer 2
προς το μοναδικό Guest interface του ASA (`Gi1/3`). Το core δεν έχει VLAN 60 SVI
και δεν κατέχει τη διεύθυνση `10.0.60.1`.

**Πώς διαβάζεται η wireless διαδρομή:** ο πραγματικός στόχος σχεδιασμού είναι
δύο autonomous APs. Για το Packet Tracer, τα δύο LAP-PT ελέγχονται κεντρικά από
το 3504 WLC. Οι ακριβείς λεπτομέρειες WLC/LAP management και CAPWAP παραμένουν
TBD.

Η κεντρική διαδρομή είναι το routed backbone. Η σύνδεση Core→ASA Guest είναι
ξεχωριστή από το routed inside link: μεταφέρει μόνο το Guest broadcast domain
προς το firewall.

Η διαδρομή management εμφανίζεται ως unchanged επειδή η απόφαση για το VLAN 60
transit δεν εξουσιοδοτεί redesign του management. Ο ακριβής φυσικός τερματισμός
της δεν επιλύθηκε από την εγκεκριμένη αλλαγή και επομένως παραμένει TBD.

Μία γραμμή ανά καλώδιο υποδομής. Τα endpoint access cables ομαδοποιούνται επειδή
η κατανομή σε επίπεδο θύρας τεκμηριώνεται στο 3.5.

|--:|-----|------|------|-----------|

| 2 | Edge 4331 Gi0/0/1 | ASA outside | Routed | `10.0.254.4/30` |
| 3 | ASA inside | Core 3650 | Routed | `10.0.254.0/30` |

| 5 | Core 3650 | Access SW1 | **802.1Q trunk** | VLANs 10, 20, 30, 40, 60, 99 |
| 6 | Core 3650 | Access SW2 | **802.1Q trunk** | VLANs 10, 20, 30, 40, 60, 99 |
| 7 | Core 3650 | 3504 WLC | WLAN VLAN trunk· management details TBD | SSID VLANs 10, 20, 30, 40, 60 |

| 9 | Core 3650 | Web server | Access | VLAN 50 |

| 11 | ASA management interface | Existing management path | **Unchanged· termination TBD** | Existing management architecture/addressing |

### Καταχωρίσεις που έχουν σημασία για τις εγκεκριμένες αλλαγές

- Οι γραμμές 5 και 6 περιλαμβάνουν πλέον το VLAN 60. Εξακολουθούν να εξαιρούν
  το VLAN 50 επειδή οι servers συνδέονται απευθείας στο core.
- Η γραμμή 4 αντικαθιστά τα δύο προηγούμενα Guest cables από τα access switches
  προς το firewall. Δεν επιβάλλει access mode ή tagged trunk/subinterface mode.
- Οι γραμμές 7, 12 και 13 είναι προσθήκες της υλοποίησης Packet Tracer. Ο στόχος
  design παραμένει δύο autonomous APs συνδεδεμένα με trunks στα access switches.

### Επαλήθευση αριθμού θυρών

| Συσκευή | Τρέχουσες φυσικές συνδέσεις | Απαίτηση | Αποτέλεσμα |
|---------|-----------------------------|----------|------------|
| Core 3650 | 8 — ASA inside, ASA Guest, 2 access switches, WLC, 3 servers | C13: ελάχιστο ≥9 για το design· το επιλεγμένο μοντέλο έχει 24 | ✓· το WLC καταναλώνει θύρα μόνο για την υλοποίηση και το μοντέλο διατηρεί μεγάλο περιθώριο |
| ASA 5506 | 4 ρόλοι — outside, inside, Guest, management | F2: ≥4 | ✓· το management παραμένει ξεχωριστό και unchanged |
| Access SW1/2 | 1 core uplink + LAP + endpoints | A10: 1 uplink | ✓· το δεύτερο Gigabit uplink δεν απαιτείται πλέον για Guest |
| Edge 4331 | 2 — ISP και firewall | E1: ≥2 | ✓· το τρίτο interface παραμένει spare |

Το ελάχιστο των εννέα θυρών του design για την C13 υπολογίζεται χωρίς το
implementation-only WLC: επτά τρέχουσες data connections, μία μελλοντική σύνδεση
File Server και μία spare. Στο Packet Tracer το WLC χρησιμοποιεί αυτή την
επιπλέον σύνδεση, αλλά το επιλεγμένο 24-port core παραμένει πολύ πάνω από το
ελάχιστο. Ο μη επιλυμένος τερματισμός του management path πρέπει να ελεγχθεί
ξεχωριστά πριν από πραγματικό build· αυτό το έγγραφο δεν τον αναθέτει σιωπηρά σε
θύρα του core.

## 3.4.4 Transit και τερματισμός Guest VLAN 60

**Επιλέχθηκε: Layer 2 transit μέσω του core, με ένα Guest gateway στο firewall.**

Το VLAN 60 ακολουθεί αυτή τη φυσική διαδρομή:

```text
LAP / wireless client → access switch → core (Layer 2 only) → ASA Guest interface
```

Το addressing παραμένει ακριβώς όπως ορίστηκε στη Φάση 2:

| Ιδιότητα | Τιμή |
|----------|------|
| Guest subnet | `10.0.60.0/24` |
| Default gateway | `10.0.60.1/24` στο ASA |
| Core VLAN 60 SVI | **Κανένα** |
| DHCP scope | Ένα scope στο ASA |

### Γιατί άλλαξε η προηγούμενη φυσική διάταξη

Η προηγούμενη διάταξη dedicated uplinks έφερνε ένα καλώδιο VLAN 60 από κάθε
access switch στο ASA. Η διατήρηση ενός subnet και ενός gateway θα απαιτούσε
τότε τα δύο ASA interfaces να γεφυρωθούν σε ένα Layer 2 domain. Το Packet Tracer
ASA δεν παρέχει την απαιτούμενη υλοποίηση bridge-group/BVI.

Ο τεμαχισμός του `/24` σε δύο `/25` δίκτυα δεν επιλέχθηκε επειδή θα άλλαζε το
addressing plan, θα δημιουργούσε δύο DHCP scopes και θα παρήγαγε δύο Guest
networks εκεί όπου ο σχεδιασμός ορίζει ένα.

Το Layer 2 transit διατηρεί το ενιαίο subnet και gateway, χρησιμοποιώντας το
κανονικό access-to-core trunk από κάθε switch. Το core προωθεί τα VLAN 60 frames,
αλλά δεν τα δρομολογεί.

### Συνθήκη απομόνωσης

Το core δεν πρέπει να έχει VLAN 60 SVI. Ο υφιστάμενος firewall rule που αρνείται
Guest traffic προς RFC1918 προορισμούς παραμένει defence in depth αν προστεθεί
κατά λάθος SVI· δεν αντικαθιστά την απαίτηση no-SVI.

### Σκόπιμα μη επιλυμένη λεπτομέρεια

Το Core→ASA handoff μπορεί να υλοποιηθεί ως untagged access port ή ως tagged
trunk/subinterface, ανάλογα με τις επιβεβαιωμένες δυνατότητες του Packet Tracer
ASA. Καμία επιλογή δεν έχει εγκριθεί, άρα το έγγραφο καταγράφει τη σύνδεση ως
**Layer 2 handoff — mode TBD**. Η επιλογή πρέπει να γίνει πριν από το
configuration και να αποτυπωθεί με συνέπεια στο 3.5.

## 3.4.5 Τοποθέτηση συσκευών

### Ομαδοποιήσεις

| Ομάδα | Συσκευές | Αιτιολογία |
|-------|----------|------------|
| **Equipment area** | Core, firewall, edge router, WLC, 3 servers | Δεν εξυπηρετούν άμεσα users· συγκεντρώνονται για physical security, περιβαλλοντικό έλεγχο και μικρές interconnects |
| **Distributed** | Access switches | Πρέπει να βρίσκονται κοντά στους users που εξυπηρετούν, αλλιώς κάθε user cable γίνεται μεγάλη διαδρομή |
| **Ceiling ή wall mounted** | LAP-PT access points | Τοποθετούνται για radio coverage· το PoE αποφεύγει την ανάγκη κοντινής mains power |

### Περιορισμός απόστασης

Το Cat6 μεταφέρει 10 Gbps περίπου έως τα 55 μέτρα. Ο σχεδιασμός προδιαγράφει
10 Gbps access-to-core uplinks, παρότι το Packet Tracer τα υλοποιεί στα 1 Gbps.
Επομένως κάθε access switch πρέπει να βρίσκεται εντός 55 μέτρων από το core ως
προς τη διαδρομή του καλωδίου· διαφορετικά απαιτείται Cat6a για εκείνο το uplink.

Δεν δόθηκαν floor plan, building layout ή αποστάσεις καλωδίων. Αυτά τα στοιχεία
δεν επινοούνται εδώ και πρέπει να επιβεβαιωθούν πριν από τη φυσική ανάπτυξη.

## 3.4.6 Διευκρινίσεις σε προηγούμενες απαιτήσεις

### F2 — τα firewall interfaces παραμένουν τέσσερα

Η απόφαση για το Layer 2 transit αλλάζει μόνο τον τρόπο με τον οποίο το VLAN 60
φτάνει στο firewall. Δεν αφαιρεί ούτε συγχωνεύει το management interface.

```text
outside + inside + ένα Guest interface + management = 4 interfaces
```

Οι δύο Guest διαδρομές συγκεντρώνονται στο Layer 2 πριν φτάσουν στο firewall,
οπότε απαιτείται μόνο ένα Guest interface. Η αρχιτεκτονική και το addressing του
management παραμένουν όπως είχαν οριστεί.

### VLANs των core-to-access trunks

Και τα δύο core-to-access trunks μεταφέρουν τα VLANs **10, 20, 30, 40, 60 και
99**. Το VLAN 60 υπάρχει επειδή πλέον διέρχεται από το core στο Layer 2. Το VLAN
50 απουσιάζει επειδή οι servers συνδέονται απευθείας στο core.

### Wireless design έναντι υλοποίησης

Ο σχεδιασμός παραμένει δύο autonomous APs με static VLAN assignment ανά SSID. Η
υλοποίηση Packet Tracer χρησιμοποιεί 3504 WLC και δύο LAP-PT αποκλειστικά επειδή
το autonomous AP model εκθέτει ένα SSID. Αυτό προσθέτει μία συσκευή, μία core
connection και ένα wireless SPOF μόνο για την υλοποίηση.

Εδώ δεν επιλέγεται WLC/LAP management VLAN, IP address ή ακριβές port mode.

## 3.4.7 Προς επαλήθευση κατά την υλοποίηση

| Στοιχείο | Κατάσταση / ερώτημα | Απαιτούμενος χειρισμός |
|----------|---------------------|------------------------|
| **Core→ASA Guest handoff** | Access port ή tagged trunk/subinterface; **TBD** | Επιβεβαίωση δυνατότητας ASA, επιλογή ενός mode και συνεπής ενημέρωση του 3.5· να μη δημιουργηθεί core VLAN 60 SVI |
| **WLC/LAP control path** | Management VLAN, addressing, LAP join path και ακριβή port modes είναι **TBD** | Επιβεβαίωση πριν από την ανάθεση θυρών· να μη συναχθεί VLAN 99 χωρίς έγκριση |
| **Access uplinks 10 Gbps** | Δεν διατίθενται στα επιλεγμένα μοντέλα Packet Tracer | Τα lab links λειτουργούν στα 1 Gbps· η απαίτηση των 10 Gbps του πραγματικού design παραμένει |
| **Τύποι θυρών 2960** | Επιβεβαιωμένες ως 24 FastEthernet access ports και 2 Gigabit uplinks | Χρήση της Gigabit θύρας για το μοναδικό core uplink· αυτό δεν αλλάζει το πλήθος θυρών της A9 |
| **Guest client isolation** | Επαλήθευση της W6 μεταξύ clients που συνδέονται σε διαφορετικά LAPs | Αν το WLC δεν μπορεί να το επιβάλει, καταγραφή του περιορισμού· δεν επιλέγεται νέα workaround εδώ |
